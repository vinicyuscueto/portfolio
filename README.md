# Portfólio

Portfólio é uma aplicação web SPA (Single Page Application) construída em React. É uma página pessoal com o objetivo de apresentar conhecimento, habilidades, certificações, experiências e projetos de forma prática.

## Tecnologias utilizadas:

- React
- TailwindCSS
- HTML
- CSS
- JavaScript
- Node
- Vite
- JSON (hospedado no GitHub Gist)
- TanStack React Query

## Estrutura do projeto:
```bash
portfolio/
├── src/
│   ├── components/
│   │   ├── Navbar
│   │   └── Loadbar
│   ├── hooks/
│   │   └── useData.js
│   ├── pages/
│   │   ├── About
│   │   ├── Home
│   │   └── Projects
├── index.html
└── package.json
```

## Execução do projeto:

#### Clone o repositório:
```bash
git clone https://github.com/vinicyuscueto/portfolio
```

#### Abrir diretório:
```bash
cd portfolio
```

#### Instalação de dependências:
```bash
npm install
```

#### Execução do projeto:
```bash
npm run dev
```
